# Contributing to Sacred Smoke

Thank you for your interest in contributing to Sacred Smoke! This document provides guidelines for contributing to the project.

## How to Contribute

### Reporting Issues

If you encounter any issues:

1. Check if the issue already exists in the [GitHub Issues](https://github.com/scaredsmoke-star/Sacred-smoke/issues)
2. If not, create a new issue with:
   - A clear, descriptive title
   - Steps to reproduce the problem
   - Expected behavior vs actual behavior
   - Your environment details (Android version, device, architecture)
   - Any relevant logs or error messages

### Suggesting Enhancements

We welcome suggestions for improvements:

1. Open a new issue with the "enhancement" label
2. Describe the enhancement in detail
3. Explain why this enhancement would be useful
4. Provide examples if applicable

### Pull Requests

To submit code changes:

1. Fork the repository
2. Create a new branch for your feature or fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes
4. Test your changes thoroughly
5. Commit with clear, descriptive messages:
   ```bash
   git commit -m "Add feature: description of what you added"
   ```
6. Push to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
7. Open a Pull Request with:
   - A clear title and description
   - Reference to any related issues
   - Details about testing performed

### Code Style

- Follow PEP 8 guidelines for Python code
- Use clear, descriptive variable and function names
- Comment complex logic
- Keep commits focused and atomic

### Testing

- Test your changes on actual Android devices or emulators when possible
- Ensure backward compatibility
- Document any new dependencies or requirements

## Questions?

If you have questions about contributing, feel free to:
- Open an issue with the "question" label
- Reach out via GitHub discussions

## Code of Conduct

Please be respectful and constructive in all interactions. We're all here to make Python on Android better!

Thank you for contributing to Sacred Smoke! 🙏
